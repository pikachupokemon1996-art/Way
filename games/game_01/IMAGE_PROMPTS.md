# IMAGE_PROMPTS — Игра 1

Ниже указаны текстовые задания для генерации ключевых ассетов игры 1.
Это не код сайта, а постановка на создание изображений.

## 1. Фон локации
**Файл:** `game1_background_terrace.webp`

**Промпт:**
Открытая каменная площадка для занятий на природе, 2D мультяшный стиль, тёплая природная палитра, мягкий утренний свет. На переднем плане должен быть каменный стол или каменная плита, на которой позже будут размещены игровые счёты. Вокруг много зелени и листвы. На заднем плане видны горы, большой водопад и спокойная вода или небольшой пруд. Без персонажей. Без текста. Без встроенного игрового интерфейса. Картинка должна хорошо работать как полноэкранный фон для браузерной игры.

## 2. Корпус счётов — спящее состояние
**Файл:** `game1_abacus_sleeping.png`

**Промпт:**
Стилизованные древние счёты-артефакт, 2D мультяшный стиль, простой вытянутый прямоугольный силуэт. Корпус выглядит как тёплый древний камень с небольшим резным орнаментом по краям. Внутренние направляющие выполнены из дерева или бронзы. Внутри два горизонтальных ряда для размещения бусин, по 9 мест в каждом ряду. Без текста. Без персонажей. Без встроенного фона. Объект должен быть удобен для наложения интерактивных бусин.
