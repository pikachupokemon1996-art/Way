# GAME_SPEC — Игра 1

## Идентификатор
`game_01`

## Рабочее название
**Испытание знаков и счёта**

## Математическая тема
- двухзначные числа;
- десятки и единицы;
- чтение и представление числа;
- связанный математический кроссворд;
- сложение, вычитание, умножение и деление.

## Сюжетная роль
Это одно из трёх испытаний Ордена.
Игрок приходит в уединённое место обучения на природе.
Главный артефакт этого испытания — древние счёты.
Сначала они выглядят как спящий предмет знания.
После прохождения двух этапов счёты пробуждаются и предлагают заключить союз.

## Визуальная концепция
- 2D мультяшный стиль;
- тёплая природная палитра;
- открытая каменная площадка;
- каменный стол или каменная плита;
- горы, водопад, спокойная вода, зелень;
- без персонажа в кадре;
- счёты-артефакт из камня и дерева;
- интерфейс не должен разрушать ощущение живой локации.

## Платформа
- только компьютерный браузер;
- мобильную адаптацию не делать.

## Структура игры
Игра состоит из двух уровней.

### Уровень 1 — счёты
Игрок получает 20 фиксированных двухзначных чисел.
Нужно выставить:
- белые бусины = десятки;
- чёрные бусины = единицы.

Уровень обучающий:
- без жизней;
- без таймера;
- без ограничения попыток.

После каждого правильного ответа игрок получает свиток с найденным числом.
Всего нужно собрать 20 свитков.

### Уровень 2 — математическая печать
Игрок получает те же 20 свитков.
Нужно восстановить связанный математический кроссворд по фиксированной схеме.

На уровне:
- 5 попыток;
- подсказок по правильным ответам нет;
- свиток можно использовать только один раз;
- неверный свиток возвращается в инвентарь и снимает 1 попытку.

## Завершение
После прохождения уровня 2:
- счёты пробуждаются;
- появляется финальная сцена;
- игрок может:
  - заключить союз;
  - пока не выбирать.

Важно:
игроку нужно напоминать, что союз можно заключить только с одним хранителем.

## Важное ограничение для Codex
Codex не должен менять:
- художественный стиль;
- числа первого уровня;
- геометрию кроссворда;
- математическое наполнение кроссворда;
- логику жизней и попыток;
- то, что счёты являются самим артефактом игры.
