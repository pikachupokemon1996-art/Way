# LEVEL_02 — Кроссворд-печать

## Статус
Зафиксированная версия механики и математического наполнения второго уровня игры 1.

## Главное правило для Codex
Не генерировать новые примеры, числа или расположение клеток.
Кроссворд фиксированный.
Использовать геометрию приложенного файла `crossword_layout_reference.png`.

На первом уровне игрок получает ровно 20 двухзначных чисел.
Во втором уровне эти же 20 чисел используются как перетаскиваемые свитки.
Каждый свиток используется ровно один раз.

## Смысл кроссворда
Это единая связанная математическая конструкция, а не набор независимых примеров.

Число, стоящее на пересечении двух выражений, одновременно является частью обоих выражений.
Четыре квадратных блока соединены четырьмя перемычками.
В каждом квадратном блоке угловые числа общие для двух соседних выражений.

Используются все четыре арифметических действия:
- сложение `+`
- вычитание `−`
- умножение `×`
- деление `÷`

Все вычисления дают целые положительные числа.

---

# 1. Геометрия схемы

Схема состоит из четырех одинаковых квадратных блоков:

- `TL` — верхний левый;
- `TR` — верхний правый;
- `BR` — нижний правый;
- `BL` — нижний левый.

Между ними находятся четыре соединительные перемычки:

- `TOP_BRIDGE` — между верхними квадратами;
- `RIGHT_BRIDGE` — между правыми квадратами;
- `BOTTOM_BRIDGE` — между нижними квадратами;
- `LEFT_BRIDGE` — между левыми квадратами.

У каждого квадратного блока есть четыре угловых числовых поля:

- `NW` — верхний левый угол;
- `NE` — верхний правый угол;
- `SE` — нижний правый угол;
- `SW` — нижний левый угол.

Также на середине каждой стороны находится напечатанное числовое значение, участвующее в выражении:

- `N_MID` — середина верхней стороны;
- `E_MID` — середина правой стороны;
- `S_MID` — середина нижней стороны;
- `W_MID` — середина левой стороны.

## Что заполняет игрок

Игрок заполняет:
- 16 угловых полей четырех квадратов;
- 4 центральных числовых поля перемычек.

Итого: **20 пустых мест = 20 свитков из первого уровня.**

Все остальные числа и математические знаки уже напечатаны на пергаменте.

`TL_E_MID × TOP_BRIDGE = TR_W_MID`

# 11. Свитки игрока

Свитки создаются из результатов первого уровня.

Набор:
`12, 17, 18, 22, 24, 26, 27, 28, 32, 36, 39, 40, 42, 43, 54, 56, 59, 72, 78, 84`

Каждый свиток:
- содержит одно число;
- может быть использован только один раз;
- после правильной установки блокируется в клетке;
- после неправильной установки возвращается в инвентарь.

---

# 12. Механика проверки

## Правильная установка
Если игрок переносит свиток в клетку, для которой это число является правильным:
- свиток фиксируется;
- клетка считается заполненной;
- свиток исчезает из доступного инвентаря;
- жизнь не снимается.

## Неправильная установка
Если число не соответствует клетке:
- свиток возвращается в инвентарь;
- снимается 1 жизнь;
- правильный ответ не показывается.

## Жизни
В начале уровня: **5 жизней**.

Подсказок с правильными ответами нет.
Доступна только техническая инструкция о том, как перетаскивать свитки.

## Прохождение
Уровень завершён, когда правильно заполнены все 20 пустых клеток.

# 13. Важное правило визуализации

На игровом пергаменте не показывать полностью готовые равенства.

Например, вместо:
`18 × 3 = 54`

игрок видит:
`[пустая клетка] × 3 = [пустая клетка]`

Для связанной стороны он видит то же самое число в общем углу,
а не отдельную дублирующую клетку.

Codex должен строить сетку по структуре референса:
`crossword_layout_reference.png`.

Нельзя заменять эту схему списком карточек, отдельными уравнениями
или двадцатью независимыми слотами.
