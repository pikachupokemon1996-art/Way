# ASSETS — Игра 1

## Статус
Зафиксированный список визуальных ассетов для игры 1 на текущем этапе.

## Общий художественный вектор
Игра 1 должна быть выполнена в 2D мультяшном стиле.
Основа атмосферы:
- тёплая природная палитра;
- много зелени;
- горы;
- вода;
- водопад;
- спокойное место для обучения;
- без персонажа в кадре;
- ощущение открытой уединённой площадки.

Сцена не должна выглядеть как сайт с тяжёлой прямоугольной UI-панелью.
Нужно сохранить ощущение мира и локации.

---

# 1. Обязательные ассеты для первого визуального пакета

## 1.1. Фон локации
**Имя файла:** `game1_background_terrace.webp`

### Назначение
Главный фон для первого и второго уровня игры 1.

### Содержимое
Открытая каменная площадка / место для занятий на природе.

### Обязательные признаки
- 2D мультяшный стиль;
- утренний мягкий свет;
- каменная площадка;
- каменный стол или каменная плита перед игроком;
- много зелени;
- большой водопад на заднем плане;
- спокойная водная гладь или пруд;
- горы на заднем плане;
- тёплая природная гамма;
- без chibi-персонажа;
- без встроенного игрового интерфейса;
- без встроенных счётов;
- без текста на изображении.

### Композиция
- нижняя часть кадра должна позволять разместить счёты;
- стол / плита должны быть видны и находиться в зоне, где удобно расположить основной игровой предмет;
- фон не должен быть слишком тёмным;
- игровая зона должна хорошо читаться поверх фона.

### Что нельзя
- не делать сцену перегруженной архитектурой;
- не делать ночь;
- не делать большое количество ярких мелких объектов, которые спорят с интерфейсом.

---

## 1.2. Корпус счётов — спящее состояние
**Имя файла:** `game1_abacus_sleeping.png`

### Назначение
Основной интерактивный предмет первого уровня.
Позже этот же предмет может быть использован как основа для пробуждённого состояния.

### Содержимое
Стилизованные счёты-артефакт Ордена.

### Обязательные признаки
- простая и надёжная прямоугольная форма;
- внешний корпус из тёплого древнего камня;
- внутренние направляющие из дерева или бронзы;
- два горизонтальных ряда;
- в каждом ряду должно быть место для 9 бусин;
- слегка резной орнамент по краям;
- без перегруза;
- без надписей на самом изображении;
- без встроенных бусин, если это мешает интерактивной механике;
- прозрачный фон.

### Важное правило
Корпус счётов должен быть отдельным ассетом.
Codex не должен рисовать окончательный внешний вид счётов только CSS-элементами.

---

## 1.3. Белая бусина
**Имя файла:** `game1_bead_white.png`

### Назначение
Интерактивная бусина верхнего ряда.

### Значение
Белые бусины обозначают десятки.

### Обязательные признаки
- хорошо читаемая форма;
- подходит по стилю к счётам;
- светлая тёплая поверхность;
- без текста;
- прозрачный фон;
- размер подходит для размещения в корпусе счётов.

---

## 1.4. Чёрная бусина
**Имя файла:** `game1_bead_black.png`

### Назначение
Интерактивная бусина нижнего ряда.

### Значение
Чёрные бусины обозначают единицы.

### Обязательные признаки
- визуально хорошо отличима от белой;
- подходит по стилю к счётам;
- тёмная поверхность;
- без текста;
- прозрачный фон;
- размер совпадает с белой бусиной по посадке в корпус.

# 2. Дополнительные обязательные UI-ассеты

## 2.1. Рамка под текущее задание
**Имя файла:** `game1_task_frame.png`

### Назначение
Декоративная рамка, в которую код вставляет текст:
- `Собери число`
- текущее число, например `59`

### Требования
- без готового текста;
- прозрачный фон;
- визуально сочетается с игрой;
- форма спокойная и читаемая;
- не должна закрывать слишком много пейзажа.

---

## 2.2. Плашка похвалы
**Имя файла:** `game1_praise_frame.png`

### Назначение
Одна и та же декоративная карточка/плашка для сообщений после правильного ответа.

### Требования
- без встроенного финального текста;
- прозрачный фон;
- код сам вставляет:
  - короткую похвалу;
  - строку с числом;
- плашка должна выглядеть дружелюбно и поощряюще;
- стиль согласован с природной локацией и счётами.

---

## 2.3. Свиток числа
**Имя файла:** `game1_scroll_number.png`

### Назначение
Основа для свитков, которые накапливаются после правильных ответов.

### Требования
- это пустая декоративная основа;
- число вставляется кодом;
- подходит и для первого уровня, и для второго;
- стиль — пергамент / свиток;
- прозрачный фон желательно сохранить.

---

## 2.4. Пергамент-кроссворд
**Имя файла:** `game1_crossword_parchment.png`

### Назначение
Основной фон второго уровня, на который накладывается математический кроссворд.

### Требования
- ощущение старого пергамента;
- без уже нарисованных ответов;
- должно быть удобно разместить структуру кроссворда из файла `crossword_layout_reference.png`;
- может содержать декоративную рамку;
- не должен быть слишком тёмным;
- должен хорошо читаться текст уравнений и пустые клетки для свитков.

---

# 3. Ассет для позднего этапа

## 3.1. Корпус счётов — пробуждённое состояние
**Имя файла:** `game1_abacus_awakened.png`

### Назначение
Используется в финальной сцене игры 1 после прохождения испытаний.

### Требования
- тот же общий силуэт, что у `game1_abacus_sleeping.png`;
- более живой и пробуждённый вид;
- можно добавить мягкое свечение, знаки, орнаменты, магический отклик;
- не превращать в чрезмерно сложный объект;
- игрок должен легко понимать, что это те же самые счёты, но пробуждённые.

# 5. Что именно НЕ должен делать Codex сам

Codex не должен:
- придумывать новую художественную концепцию игры 1;
- заменять природную сцену на интерьер;
- вставлять chibi-персонажа;
- делать мобильную адаптацию;
- превращать счёты в абстрактный CSS-блок без графического корпуса;
- заменять свитки простыми текстовыми прямоугольниками, если ассет уже есть;
- менять цветовую гамму на холодную или мрачную.
