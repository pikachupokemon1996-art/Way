# LEVEL_01 — Собери тройку

На поле 12 закрытых карточек.
Игрок открывает ровно 3 за ход.

Правильная тройка остаётся открытой.
Неправильная тройка через короткое время закрывается.
Штрафов нет.

Группы:

### Периметр квадрата
- картинка: квадратная грядка, подчёркнута внешняя граница;
- объяснение: `Периметр квадрата — сумма длин всех четырёх его сторон.`
- формула: `P = 4a`

### Площадь квадрата
- картинка: квадратная грядка, выделена внутренняя поверхность;
- объяснение: `Площадь квадрата показывает, сколько места занимает его поверхность.`
- формула: `S = a²`

### Периметр прямоугольника
- картинка: прямоугольный участок, подчёркнута внешняя граница;
- объяснение: `Периметр прямоугольника — сумма длин всех его сторон.`
- формула: `P = 2(a + b)`

### Площадь прямоугольника
- картинка: прямоугольная грядка, выделена внутренняя поверхность;
- объяснение: `Площадь прямоугольника показывает, сколько места занимает его поверхность.`
- формула: `S = a × b`

Порядок фиксирован в `CONTENT.json`.
