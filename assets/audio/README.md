# Audio

`background_music.wav` — готовая спокойная фоновая петля на пентатонической основе.
Громкость в игре: примерно 0.18–0.25.

Это атмосферная игровая музыка, а не историческая реконструкция.

Короткие эффекты можно синтезировать Web Audio API:
- click
- correct
- error
- awaken
- small bells
- central bell
