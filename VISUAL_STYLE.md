# VISUAL_STYLE

Главный референс:
`references/game_visual_style_reference.png`

Использовать его как ориентир:
- 2D cartoon / chibi-inspired game art;
- тёплая природная палитра;
- мягкие формы;
- качественный игровой UI;
- дерево, камень, бронза, нефрит, пергамент;
- много изображений и хорошая читаемость.

НЕ копировать персонажа из референса.
Персонажи в текущей версии не нужны.

Избегать:
- фотореализма;
- 3D;
- sci-fi;
- неона;
- холодной мрачной палитры.

Текст на UI накладывать кодом, а не встраивать в картинки.
