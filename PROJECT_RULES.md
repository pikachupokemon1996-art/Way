# PROJECT_RULES

- HTML5 + CSS3 + Vanilla JavaScript.
- Статическое SPA в одном `index.html`.
- Без React/Vue/Angular, сервера, базы данных и тяжёлых библиотек.
- Desktop first; ориентир 1440×900.
- При ширине меньше 1100 px показать предупреждение:
  `Эта версия предназначена для компьютера. Открой сайт в браузере на компьютере.`
- Максимально использовать изображения.
- Ключевые игровые предметы не заменять финально CSS-прямоугольниками.
- 2D, без 3D.
- Обязательны музыка и звуки.
- Фоновая музыка: `assets/audio/background_music.wav`.
- Короткие эффекты допустимо синтезировать Web Audio API.
- Не использовать localStorage и постоянное сохранение.
- Не добавлять очки, рейтинг, таймер, регистрацию.
- Первый этап игр — обучение, второй — испытание.
- Хранителя можно выбрать только одного.
