## Математическая печать игры 1
Не используй генеративную картинку для математических чисел и операторов, если она может исказить математику.

Предпочтительный путь:
- создать отдельный статический SVG на основе пользовательского макета;
- внутри SVG точно отрисовать линии, фиксированные числа, операторы и `=`;
- оставить 20 пустых мест;
- поверх SVG разместить только 20 HTML drop-zones;
- сохранить существующие правильные ответы и drag-and-drop.

Это визуальная переработка, не новая математика.

## Состояние отказа
Добавь in-memory state для блокировки дверей:

например:
`blocked = { game_01:false, game_02:false, game_03:false }`

Обычный возврат с обучающего уровня:
НЕ блокирует.

`Сдаться` / `Отказаться от испытания` на втором уровне:
- вернуть в зал;
- установить blocked соответствующей игры;
- больше не разрешать вход в неё в текущей сессии.

После перезагрузки страницы блокировка может сбрасываться.
localStorage не использовать.
