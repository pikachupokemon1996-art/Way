# Пакет постановки задачи для Codex

Это полный пакет спецификаций, контента, референсов и промптов для сборки сайта Codex'ом.

## Как использовать
1. Распакуй архив в новую пустую папку.
2. Открой папку в Codex.
3. Открой `CODEX_MASTER_PROMPT.md`.
4. Отправь его Codex целиком одним сообщением.
5. Codex должен собрать сайт без дополнительных уточнений, если ответ уже есть в файлах.

## Архитектура
Статическое SPA: HTML + CSS + Vanilla JavaScript, без фреймворков и сервера.

## Важно
Проект только для компьютерного браузера.
Мобильную адаптацию не делать.
